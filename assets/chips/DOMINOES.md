# Domino concepts

Domino concept v1 contains six face examples and branded back. Visual counts checked: 0-0, 0-6, 1-2, 3-4, 5-5, 6-6. This is NOT a complete double-six set. Complete production double-six set requires 28 unique unordered pairs (0 through 6) with deterministic pip placement, consistent tile sizing, separate assets, and the same shared back.
